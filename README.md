# Arctic Map — обучающее веб-приложение
## Тема: «Арктические экспедиции: звёздный маршрут»

### Описание
Это обучающее веб-приложение, в котором пользователь проходит этапы освоения Арктики.
Для каждого этапа доступен короткий текст и мини-вопрос. Прогресс сохраняется на компьютере.

### Основные возможности
- Интерактивный список этапов
- Модальное окно с фактом и вопросом
- Подсчёт прогресса и правильных ответов
- Сброс прогресса
- Страница «Материалы» для дальнейшего изучения.

### Как запустить (офлайн, без установки)
1. Скачать/распаковать папку проекта.
2. Открыть файл `index.html` двойным кликом.
