## Интерактивная карта "Арктические экспедиции: звездный маршрут"

### Инструкции по запуску
1. Установите [Javascript](https://nodejs.org), [npm](https://www.npmjs.com/), [git](https://git-scm.com/) на свою систему, если они еще не установлены.
2. Скачайте исходные файлы проекта через Github страницу или с помощью git:
```
git clone https://github.com/Naakinn/arctic-map.git
```
3. Зайдя в папку с проектом, инициализируйте его:
```
npm install
```
4. Запустите проект:
```
npm start
```
5. Интернет приложение расположено по ссылке http://localhost:8080
